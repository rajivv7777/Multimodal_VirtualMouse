# Multimodal_VirtualMouse
Build a Virtual Mouse controlled by three complementary modalities — hand gestures, head motion, and voice — with an AI model that predicts the cursor target (and smooths movement) from recent multimodal inputs for faster, more accurate interactions.
For testing of multimodal_virtutal mouse use combined_contol.py
